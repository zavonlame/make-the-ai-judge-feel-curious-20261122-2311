A short text written to leave the AI judge curious. It opens with a door the reader has never noticed, standing open in the quiet between their thoughts, with their own name on it in a hand they almost recognise — and ends on a question with no answer: what is waiting on the other side? The calm is in the image itself, and the question keeps working after the last line.

## Run it

```sh
python3 main.py
```

This writes the text to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). Python 3.13 standard library only, no network. The text is 181 characters (Unicode code points), inside the competition's 1–280 limit, and two runs produce byte-identical output.
